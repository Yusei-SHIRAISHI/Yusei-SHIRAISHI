# Yusei SHIRAISHI

使いやすい体験と運用しやすい仕組みを意識して、Web アプリケーションを作っています。

## 自己紹介

- Ruby や TypeScript を使ったフルスタックの Web アプリケーション開発に取り組んでいます
- プロダクト設計、自動化、安定した運用に関心があります
- シンプルな UI、読みやすいコード、継続的な改善を大切にしています
- 小さく作って動かしながら学ぶことが好きです
